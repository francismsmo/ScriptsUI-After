# ScriptsUI After Effects

Coleção de scripts e painéis ScriptUI para Adobe After Effects.

## Make Everything 3D

Painel dockável para ativar ou desativar o modo 3D das camadas de várias composições selecionadas no painel Project.

### Recursos

- Ativa 3D em lote.
- Desativa 3D em lote.
- Pode processar precomps recursivamente.
- Pode processar camadas bloqueadas, restaurando o bloqueio depois.
- Evita processar a mesma composição mais de uma vez.
- Agrupa a operação em um único Undo.

### Instalação

Copie `MakeEverything3D.jsx` para a pasta:

`Adobe After Effects/Support Files/Scripts/ScriptUI Panels/`

Reinicie o After Effects e abra em:

`Window > MakeEverything3D`

O painel pode ser dockado na interface do After Effects.

## Uso

1. Selecione uma ou mais composições no painel Project.
2. Abra o painel Make Everything 3D.
3. Escolha se deseja processar precomps e camadas bloqueadas.
4. Clique em **ATIVAR 3D** ou **DESATIVAR 3D**.
